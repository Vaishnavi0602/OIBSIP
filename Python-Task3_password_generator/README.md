# Advanced Random Password Generator

## Oasis Infobyte Internship

### Python Programming - Task 3

## Description

This project is a GUI-based Random Password Generator developed using Python and Tkinter.

It generates strong and secure passwords using Python's built-in `secrets` module and allows users to customize password length and character types.

---

## Features

- Generate Secure Passwords
- Modern Tkinter GUI
- Password Length Selector
- Uppercase Letters
- Lowercase Letters
- Numbers
- Symbols
- Exclude Similar Characters (0 O l 1)
- Password Strength Indicator
- Copy Password to Clipboard
- Last 5 Password History

---

## Technologies Used

- Python
- Tkinter
- Secrets Module
