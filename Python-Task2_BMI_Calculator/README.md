# Advanced BMI Calculator

## Oasis Infobyte Internship
**Track:** Python Programming

## Project Description

Advanced BMI Calculator is a Python GUI application that calculates a user's Body Mass Index (BMI), classifies the health status, stores records in an SQLite database, displays previous records, and plots BMI trends over time.

## Features

- GUI built using Tkinter
- Calculate BMI instantly
- BMI Classification:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Color-coded BMI result
- Save records into SQLite database
- Multi-user support
- View BMI history
- Display BMI trend graph using Matplotlib
- Input validation
- Database error handling

## Technologies Used

- Python 3
- Tkinter
- SQLite3
- Matplotlib

## Installation

Install the required package:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python main.py
```

## Formula Used

BMI = Weight (kg) / Height² (m²)
